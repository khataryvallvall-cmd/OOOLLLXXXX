# تجهيز التطبيق للنشر على GitHub Pages

## الملفات
- `index.html` — التطبيق نفسه (بعد إضافة القفل الاختياري وسلوك التطبيق الأصلي)
- `manifest.json` — ملف تعريف PWA (اسم التطبيق، الألوان، الأيقونات)
- `service-worker.js` — يجعل التطبيق يفتح فورًا وبدون شريط المتصفح بعد إضافته للشاشة الرئيسية
- `icon-192.png`, `icon-512.png` — أيقونة التطبيق (خلفية صفراء بلون التطبيق وحرف U في المنتصف)
- `icon-192-maskable.png`, `icon-512-maskable.png` — نفس الأيقونة بدون زوايا دائرية، تُستخدم في أندرويد ليقوم النظام بقص الشكل بنفسه (دائرة/مربع مدوّر حسب جهاز المستخدم) دون أن يقتطع جزءًا من الحرف

## خطوات النشر
1. أنشئ مستودع (repository) جديد على GitHub، مثلاً باسم `video-cards-app`.
2. ارفع كل الملفات أعلاه في **جذر** المستودع مباشرة (وليس داخل مجلد فرعي) بنفس الأسماء تمامًا.
3. من إعدادات المستودع: `Settings → Pages` اختر `Branch: main` و`Folder: / (root)` ثم احفظ.
4. بعد دقيقة أو دقيقتين سيظهر رابط الموقع، مثل:
   `https://username.github.io/video-cards-app/`
5. افتح الرابط من متصفح الجوال (Chrome على أندرويد)، ثم من قائمة المتصفح اختر **"إضافة إلى الشاشة الرئيسية" / Add to Home screen**. ستظهر أيقونة التطبيق (الصفراء بحرف U) على شاشة الهاتف، وعند فتحه سيعمل بملء الشاشة بدون أي شريط متصفح — تمامًا كتطبيق أندرويد عادي.

## آلية القفل (محدَّثة)
- التطبيق **يفتح مباشرة** على المحتوى دون أي انتظار لكلمة مرور.
- زر القفل 🔒 في الشريط العلوي:
  - إن لم يوجد رمز محفوظ بعد → يفتح شاشة **إنشاء رمز** (لوحة أرقام فقط، الأرقام تظهر واضحة أثناء الإنشاء والتأكيد).
  - إن وُجد رمز محفوظ مسبقًا → يقفل الشاشة فورًا ويطلب إدخال الرمز (الأرقام تظهر كنقاط مخفية هذه المرة) للعودة إلى المحتوى.
- الرمز يُحفظ على جهاز المستخدم فقط (لا يُرسل لأي خادم)، بصيغة مُجزّأة (hash) وليس نصًا صريحًا.
- إذا نسي المستخدم الرمز أثناء شاشة القفل: زر "نسيت الرمز؟ إعادة الضبط" يمسحه ليُنشئ رمزًا جديدًا (لا يمسح باقي بيانات التطبيق).

## ملاحظات أخرى
- روابط الفيديو في المتغير `VIDEO_LINKS_RAW` تبقى كما كانت — لم تُغيَّر آلية إضافة الروابط.
- تجربة إخفاء التحديد/النسخ ومظهر الأيقونة الكامل لن يظهرا بشكل كامل داخل معاينة الأدوات هنا، لكنهما يعملان بشكل صحيح على GitHub Pages وعند تشغيله كتطبيق مضاف للشاشة الرئيسية.
